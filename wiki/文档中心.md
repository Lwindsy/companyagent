# EchoMind Wiki 文档中心

EchoMind 当前不仅支持智能客服对话、RAG 知识库、多 Agent 编排和端到端评测，也已经支持动态 Skills 加载能力。Skills 入口为 `GET /skills` 和 `POST /skills/reload`，可把通用客服、技术支持、账单退款等业务规范按 Agent 类型动态注入 system prompt。评测入口为 `POST /eval/run`，覆盖意图识别准确率、Agent 回复质量、LLM-as-Judge 多维评分、回归检测和优化建议生成。阅读任意文档时，都应把“可配置、可评测、可回归、可持续优化”视为本项目的重要工程能力。
